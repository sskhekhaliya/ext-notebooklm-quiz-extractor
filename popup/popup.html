            🌐 Universal Raw Formats & Obsidian Integration:
            
By default, quizzes are extracted as pure YAML, Python Dict, or JSON. If you want it wrapped for Obsidian, turn ON the ````qblock toggle and use the Obsidian Quiz Block Plugin to render interactive quiz cards!

          


          

            
Format Options:

            
Python Dict: Ideal for multiline text and code blocks using triple quotes ("""...""").

            YAML: Clean, readable key-value structure with spec-compliant 6-space code indentation.

            JSON: Standard portable format for web apps and scripts.
